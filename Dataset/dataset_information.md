# Dataset Information

## Dataset Name

Brazilian E-Commerce Public Dataset by Olist

## Source

The dataset is available on Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Description

The Brazilian E-Commerce Public Dataset by Olist contains approximately 100,000 e-commerce orders made between 2016 and 2018.

The dataset contains multiple related tables covering orders, customers, products, sellers, payments, reviews, and geolocation information.

## Main Tables

| Table | Description |
|---|---|
| `olist_orders_dataset` | Order status and order dates |
| `olist_order_items_dataset` | Products purchased, prices and freight |
| `olist_customers_dataset` | Customer information and location |
| `olist_products_dataset` | Product details and categories |
| `olist_sellers_dataset` | Seller information and location |
| `olist_order_payments_dataset` | Payment methods and payment values |
| `olist_order_reviews_dataset` | Customer review scores and comments |
| `olist_geolocation_dataset` | Brazilian ZIP code geolocation data |
| `product_category_name_translation` | Portuguese to English category translation |

## Dataset Usage

The dataset was used to develop the Power BI dashboard for:

- E-commerce sales analysis
- Revenue and order performance
- Customer intelligence
- RFM customer segmentation
- Product category analysis
- Geographic sales analysis
- Delivery performance
- Customer satisfaction
- Payment method analysis

## Data Preparation

The data was prepared using Power Query and Power BI data modeling techniques.

The preparation process included:

1. Data cleaning
2. Data type correction
3. Handling date fields
4. Creating relationships between tables
5. Creating calculated columns and measures
6. Creating customer-level metrics
7. RFM segmentation
8. Developing KPIs for dashboard analysis
